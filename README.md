# AhmadOS

My personal portfolio, built as a retro desktop operating system that runs in the browser.

**Live demo:** https://your-site-url-here

## What it is

Instead of a normal scrolling page, the portfolio is a small desktop with windows. Each section (profile, education, skills, projects, contact) is an application you open from a desktop icon.

- Draggable windows with minimize, maximize and close
- Top menu bar, right-click desktop menu and a taskbar
- A working terminal (`help`, `whoami`, `projects`, `skills`, `contact`, `github`, `dir`, `clear`, `date`, `version`, `exit`)
- Keyboard support for menus (arrow keys, Enter, Escape)
- Boot screen and CRT effect, with reduced-motion support
- Responsive layout for small screens

## Tech

Plain HTML, CSS and JavaScript. No frameworks, no build step, and everything lives in a single `index.html` file.

## Run locally

Open `index.html` in any modern browser.

## Edit the content

All the portfolio content (name, summary, education, skills, projects, links) is in the `D` object at the top of the `<script>` tag in `index.html`. Change the values there and the windows and terminal update automatically.
